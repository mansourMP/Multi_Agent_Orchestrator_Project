- **Workflows:** Visual definitions stringified in DB, traversable graph logic on backend.

### Key Logic: Graph Traversal
The `ExecutionsService` is now a recursive (while-loop) engine that finds the `trigger`, follows `edges`, evaluates `logic` conditions via safe script evaluation, and propagates a unified `context` object between nodes.
