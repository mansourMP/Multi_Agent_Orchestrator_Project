## 🎨 **Design System**

### **Typography**
```
Font Family:  Inter (body), JetBrains Mono (code)
Base Size:    13px (desktop standard, NOT 16px)
Line Height:  1.4 (tight, NOT 1.6)
Weights:      400, 500, 600, 700
Scale:        11px, 12px, 13px, 14px, 16px, 18px, 20px
```

### **Spacing (8px Grid)**
```
Micro:    2px, 4px, 6px
Standard: 8px, 12px, 16px
Large:    20px, 24px, 32px

Node padding:     8-12px (not 24px)
Table row:        36px height
Button padding:   6-8px vertical
```

### **Color Palette**
```css
/* Professional (Muted) */
--bg-app:        #0f172a  /* Main */
--bg-surface:    #1e293b  /* Panels */
--text-primary:  #f1f5f9  /* Main text */

/* Circuit Theme */
--pcb-bg:        #0a1810  /* PCB green */
--pcb-trace:     #00d4ff  /* Electric cyan */
--electric-green:#00ff88  /* Active */
--electric-amber:#ffaa00  /* Warning */
```

## ⚡ **Circuit Board Theme Details**

### **Concept:**
"Conductor" = electrical conductor → AI agents as logic gates on a circuit board

### **Logic Gate Mapping:**
| Agent Type | Gate | Shape | Why |
|------------|------|-------|-----|
| Vision AI | AND | `D` | Combines inputs (pixels) |
| Coding Agent | XOR | `◇` | Decision logic (if/else) |
| Research | OR | `)` | Multiple sources → 1 output |
| Standard | Buffer | `→` | Simple flow |
| CEO/Premium | NAND | Complex | Multi-stage |

### **Animations:**
```css
@keyframes pulse-signal      /* Node glows during execution */
@keyframes electric-flow     /* Dots travel along traces */
@keyframes blink-signal      /* LED status indicator */
@keyframes execute-glow      /* Rhythmic processing glow */
```

### **Canvas Features:**
- **Background:** PCB green (#0a1810) with dots + grid lines
- **Connections:** Electric cyan (#00d4ff), 3px width, animated
- **Minimap:** "Circuit Overview" (bottom-right)
- **Controls:** Glowing zoom buttons
- **Grid:** 20px × 20px snapping
