## 🎬 HOW TO SEE IT

### Option 1: Change System Theme
**Mac**:
```
System Settings → Appearance → Light
```

**Windows**:
```
Settings → Personalization → Colors → Light
```

### Option 2: Browser DevTools
```
1. Open DevTools (F12)
2. Cmd+Shift+P (Mac) / Ctrl+Shift+P (Windows)
3. Type "Render"
4. Select "Emulate CSS prefers-color-scheme: light"
```

### Option 3: Hard Refresh
```
Cmd + Shift + R (Mac)
Ctrl + Shift + R (Windows)
```
